`AgenticOps-GBO <agenticops@…>`, mensajes internos (carriles, backlog, worktrees). El **contenido** de `frameback/`
está limpio (escaneado: sin rutas de la máquina, correos, secretos ni referencias privadas).
**Recomiendo:** repo nuevo con historia limpia, un solo commit inicial con tu identidad pública:

```sh
rsync -a --exclude node_modules --exclude dist --exclude examples/demo \
  ~/claude-work/video-creation/gbo-video-editor/frameback/ ~/code/frameback/
cd ~/code/frameback && git init -b main
git -c user.name="Guillermo Becerra" -c user.email="<tu correo público>" commit --allow-empty -m init  # opcional
git add -A && git -c user.name="Guillermo Becerra" -c user.email="<tu correo público>" commit -m "Frameback v0.1.0"
gh repo create <usuario>/frameback --public --source . --push     # cuando quieras
```
