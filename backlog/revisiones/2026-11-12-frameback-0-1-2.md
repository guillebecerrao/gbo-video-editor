**Cómo marcar:** cambia `[ ]` por `[x]` funciona · `[~]` funciona, con comentario · `[!]` falla. O dímelo por el chat («V1 ok, V3 falla porque…»).

## Preparación (una vez, en el Mac donde edita el agente)

```sh
cd gbo-video-editor && git pull
cd frameback && npm ci && npm run build && npm link   # deja el comando `frameback` apuntando a esta versión
frameback --version                                   # debe responder (versión 0.1.1 en el número; el código es el nuevo)
```

Al terminar de validar: `npm unlink -g frameback` para volver a la de npm.
