# Pipeline de experimentación

> Estado vivo de los experimentos. Se diseñan en Handoff con `disenar-experimento` (umbral pre-registrado, sin excepciones; el experimento se recomienda, no se exige), se lanzan tras Build y se deciden con `decision-ship` (decisión humana). Una fila por experimento.

| ID | Feature | Método | Lanzado | Corte | Estado | Decisión |
|----|---------|--------|---------|-------|--------|----------|

*Estados: diseñado → running → leído → decidido. La decisión y su criterio viven en el doc del experimento (`experimentos/EXP-NN-*.md`).*
